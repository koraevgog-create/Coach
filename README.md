# Молчаливый наставник

Статический сайт с вопросами для самостоятельных размышлений.

## Функции
- Короткий запрос до 100 символов
- 23 тематические категории и 30 универсальных вопросов
- 10 дополнительных вопросных шаблонов для каждой тематики
- Кнопка «Ещё один вопрос» без повторов в цикле
- Избранное (localStorage), копирование, мобильная адаптация
- Без регистрации, API и отправки запросов на сервер

Откройте index.html локально или опубликуйте корень ветки main через GitHub Pages.

Это подбор по ключевым словам, а не генеративный ИИ. Сервис не заменяет специалиста.
