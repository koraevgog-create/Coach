# Пламя Семи Башен

Браузерная Tower Defense игра.

## Структура

- `index.html` — только разметка страницы и подключение файлов.
- `css/styles.css` — весь интерфейс и адаптивные стили.
- `js/game.js` — игровая логика и отрисовка.
- `assets/` — изображения и другие игровые ресурсы.

## Правила разработки

1. Не возвращать CSS и JavaScript обратно в `index.html`.
2. Один логический этап — один отдельный коммит.
3. Перед крупной визуальной интеграцией сохранять стабильную версию.
4. Новые ассеты сначала добавлять в `assets/`, затем подключать их отдельным коммитом.
5. Не менять одновременно игровую механику и большой пакет графики.
6. GitHub Pages должен всегда запускаться напрямую из корня репозитория.

Текущая стабильная основа: v0.2.3.
